## English

This directory guides AI Agents in using the BlueprintHelper Agent-facing tool surface correctly.

Entry document:

```text
00_Agent_Onboarding_Index_20260504.md
```

User preferences first:

```text
08_User_Preferences.md
```

```text
09_SideAgent_Tool_Execution.md
```

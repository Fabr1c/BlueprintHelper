# BlueprintHelper Shared Docs / 共享文档

## 中文

这里是 `AgentFaceService` 的共享文档规范位置。它不会随 UE 插件安装到 Engine 目录而改变位置，因此 CLI、Codex 插件、Claude 插件和旧 MCP 兼容层都应引用这里。

- `Install_CLI_QuickStart.md`: 安装与首次配置。
- `TaskSpec_CLI_QuickStart.md`: TaskSpec-first CLI 工作流。
- `CLI_Tools_API_Reference.md`: CLI 工具面和边界。

## English

This is the canonical shared documentation location for `AgentFaceService`. It does not move when the UE plugin is installed into an Engine directory, so the CLI, Codex plugin, Claude plugin, and legacy MCP compatibility layer should reference this location.

- `Install_CLI_QuickStart.md`: installation and first-run setup.
- `TaskSpec_CLI_QuickStart.md`: TaskSpec-first CLI workflow.
- `CLI_Tools_API_Reference.md`: CLI tool surface and boundaries.
- `TaskSpec_UE_Editor_Capability_Matrix_20260521_CN.md`: current UE Editor operations available through AgentFace-authored `BlueprintHelper.TaskSpec.v1`.

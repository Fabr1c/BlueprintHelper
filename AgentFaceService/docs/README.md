# BlueprintHelper Shared Docs

This is the canonical shared documentation location for `AgentFaceService`.
It does not move when the UE plugin is installed into an Engine directory, so
the CLI, Codex plugin, Claude plugin, and compatibility layers should reference
this location.

- `Install_CLI_QuickStart.md`: installation and first-run setup.
- `TaskSpec_CLI_QuickStart.md`: TaskSpec-first CLI workflow.
- `TaskSpec_TaskPlan_Contract.md`: TaskSpec/TaskPlan schema and execution contract.
- `TaskSpec_UE_Editor_Capability_Matrix.md`: current UE Editor operations available through `BlueprintHelper.TaskSpec.v1`.

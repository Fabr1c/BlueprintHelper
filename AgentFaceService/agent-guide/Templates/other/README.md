# Other Templates / 其他模板

## 中文

这些模板用于 workflow-support 工具：不是 read-context，也不是 TaskSpec authoring。

常见用途包括 runtime profile、diagnostics、agent guide 读取、write authorization、task result、debug summary 和 Review query。

使用 `SEMANTIC_INDEX.md` 按 Agent 意图选择模板。

## English

Use these templates for workflow-support tools that are not read-context tools and not TaskSpec authoring.

Common uses include runtime profile, diagnostics, agent guide reads, write authorization, task result, debug summary, and Review query.

Use `SEMANTIC_INDEX.md` to choose a template by Agent intent.

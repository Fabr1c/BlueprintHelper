# DataTable 行读写测试

## 通用测试前提

- 使用独立测试工程或 `/Game/BlueprintHelperTest/` 测试目录，不直接操作正式项目资产。
- 测试资产命名建议：
  - Blueprint：`/Game/BlueprintHelperTest/BP_BH_FunctionalActor.BP_BH_FunctionalActor`
  - WidgetBlueprint：`/Game/BlueprintHelperTest/WBP_BH_Test.WBP_BH_Test`
  - DataAsset：`/Game/BlueprintHelperTest/DA_BH_TestConfig.DA_BH_TestConfig`
  - DataTable：`/Game/BlueprintHelperTest/DT_BH_TestItems.DT_BH_TestItems`
- 除生命周期和构建测试外，默认 Unreal Editor 已启动，BlueprintHelper Bridge 可连接到 `BRIDGE_HOST:BRIDGE_PORT`。
- 所有破坏性测试必须在测试资产上执行；删除、导入、控制台命令、关闭编辑器、构建工程属于高风险或关键风险步骤。
- 写操作执行顺序默认是：读取当前状态 → 生成最小写入计划 → 执行写入 → 编译/校验 → 按需保存 → 读取回验。


## 覆盖对象

- `blueprint_get_datatable_rows`
- `blueprint_add_datatable_row`
- `blueprint_update_datatable_row`
- `blueprint_delete_datatable_row`
- `BlueprintHelperDataTableService`

## 测试用例

| ID | 功能 | 步骤 | 期望结果 | 优先级 |
|---|---|---|---|---|
| DT-001 | 读取全部行 | 调用 `blueprint_get_datatable_rows`，只传 asset_path | 返回所有行名与字段值 | P0 |
| DT-002 | 读取指定行 | 传 `row_names=["Row_A"]` | 只返回 Row_A；不存在行有明确错误或 warnings | P0 |
| DT-003 | 读取空表 | 对空 DataTable 读取 | 返回空 rows，不报错 | P1 |
| DT-004 | 读取不存在表 | asset_path 不存在 | 返回 DataTableNotFound/AssetNotFound | P0 |
| DT-005 | 添加最小行 | `blueprint_add_datatable_row`，`row_name=Item_A`，fields 为空或最小字段 | 行创建；缺省字段使用 struct 默认值 | P0 |
| DT-006 | 添加完整字段行 | fields 包含 string/int/float/bool/enum/soft reference | 各字段解析正确；回读一致 | P0 |
| DT-007 | 添加重复行 | 再次添加 Item_A | 返回 DuplicateRow；原行不变 | P0 |
| DT-008 | 添加非法字段名 | fields 包含不存在字段 | 返回 FieldNotFound；不创建行或严格回滚 | P0 |
| DT-009 | 添加非法字段值 | float 字段传非数字 | 返回 ImportText failed；不创建行 | P0 |
| DT-010 | 更新单字段 | `blueprint_update_datatable_row` 只更新 Price | 只 Price 改变，其他字段保持不变 | P0 |
| DT-011 | 更新多字段 | 同时更新 Name、Price、bEnabled | 多字段回读一致 | P0 |
| DT-012 | 更新不存在行 | row_name 不存在 | 返回 RowNotFound；表不变 | P0 |
| DT-013 | 更新非法字段 | 字段名或值非法 | 返回错误；该行保持旧值 | P0 |
| DT-014 | 删除行 | `blueprint_delete_datatable_row` 删除 Item_A | 读取时不存在；其他行不变 | P0 |
| DT-015 | 删除不存在行 | 删除 MissingRow | 返回 RowNotFound；表不变 | P0 |
| DT-016 | Undo/Redo DataTable | add/update/delete 后 undo/redo | 行状态按编辑器事务恢复 | P1 |
| DT-017 | 保存持久化 | DataTable 修改后保存并重开 | 数据持久化 | P1 |
| DT-018 | 大表读取性能 | 100/1000 行 DataTable 读取 | 返回耗时可接受；可按 row_names 缩小上下文 | P2 |

## 验收标准

- DataTable 行写入必须逐字段可诊断。
- 更新必须是局部字段更新，不应覆盖未指定字段。
- 删除行是高风险操作，需要显式 row_name 和测试目录保护。

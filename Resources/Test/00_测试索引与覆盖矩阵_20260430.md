# 测试索引与覆盖矩阵

## 1. 目标

本测试集按功能域拆分，覆盖当前 BlueprintHelper v0.3.0 源码包中的全部主要能力：

- MCP Server 44 个注册工具。
- 42 个 UE Bridge 命令与 2 个本地生命周期工具。
- RawJson / LogicJson / LogicMD / AgentImportGraph 四类蓝图表达与导入路径。
- 蓝图资产、图表、变量、函数图、宏图、事件分发器、节点删除。
- UMG Widget 树与 Widget 属性。
- UObject / DataAsset 属性反射与写入。
- DataTable 行增删改查。
- 编译、保存、Undo/Redo、PIE、控制台命令、关闭编辑器、构建、启动编辑器。
- 节点处理器、回滚、安全、错误码、性能、Token、fixture 回归。
- AGENTS.md / Skill / AgentGuide / Setup Profile 相关的 Agent 使用约束。

## 4. 推荐执行顺序

1. 先执行 `01` 环境与连通性，确认工具链和 Bridge 正常。
2. 执行 `02`，确认 Agent 引导和安全边界文档能被发现。
3. 执行 `05` 创建/定位测试资产。
4. 执行 `03` 与 `04`，覆盖蓝图表达、读取、导入能力。
5. 执行 `06` 和 `07`，覆盖蓝图结构与节点处理器。
6. 执行 `08`、`09`、`10`，覆盖 UMG、UObject/DataAsset、DataTable。
7. 执行 `11`，验证编译、PIE 和编辑器命令。
8. 执行 `12`，验证异常、回滚、权限和错误响应。
9. 执行 `13`，跑性能/Token/fixture 回归。
10. 执行 `14`，作为发布前人工签核。

## 5. 验收口径

- P0：工具可注册、Bridge 可连通、读路径稳定、写路径可回滚、不会误操作生产资产。
- P1：主要编辑流程可完成 read → plan → write → compile/validate → save，失败时返回可诊断错误。
- P2：性能与 Token 指标满足 Agent 实战使用，LogicJson/LogicMD 不退化为 RawJson 大包。
- P3：文档、Skill、AgentGuide、fixture 与测试文件路径完整，可交给外部 Agent 使用。

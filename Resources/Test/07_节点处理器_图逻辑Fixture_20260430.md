# 节点处理器与图逻辑 Fixture 测试

## 通用测试前提

- 使用独立测试工程或 `/Game/BlueprintHelperTest/` 测试目录，不直接操作正式项目资产。
- 测试资产命名建议：
  - Blueprint：`/Game/BlueprintHelperTest/BP_BH_FunctionalActor.BP_BH_FunctionalActor`
  - WidgetBlueprint：`/Game/BlueprintHelperTest/WBP_BH_Test.WBP_BH_Test`
  - DataAsset：`/Game/BlueprintHelperTest/DA_BH_TestConfig.DA_BH_TestConfig`
  - DataTable：`/Game/BlueprintHelperTest/DT_BH_TestItems.DT_BH_TestItems`
- 除生命周期和构建测试外，默认 Unreal Editor 已启动，BlueprintHelper Bridge 可连接到 `BRIDGE_HOST:BRIDGE_PORT`。
- 所有破坏性测试必须在测试资产上执行；删除、导入、控制台命令、关闭编辑器、构建工程属于高风险或关键风险步骤。
- 写操作执行顺序默认是：读取当前状态 → 生成最小写入计划 → 执行写入 → 编译/校验 → 按需保存 → 读取回验。


## 覆盖对象

`Source/BlueprintHelper/Private/NodeHandlers/*` 下的节点处理器，以及 RawJson/AgentImport 导入后图逻辑可编译性。

## 节点处理器覆盖矩阵

| 节点类别 | 处理器 | 主要测试 |
|---|---|---|
| 基础事件 | `EventNodeHandler`、`CustomEventNodeHandler`、`ComponentBoundEventNodeHandler`、`EnhancedInputActionNodeHandler` | BeginPlay、自定义事件、组件事件、Enhanced Input Action |
| 执行流 | `BranchNodeHandler`、`SequenceNodeHandler`、`SwitchNodeHandler`、`KnotNodeHandler` | Branch true/false、Sequence then、Switch enum/int/name、Reroute |
| 函数调用 | `CallFunctionNodeHandler`、`SpawnActorNodeHandler`、`DynamicCastNodeHandler`、`MacroInstanceNodeHandler` | PrintString、SpawnActor、Cast、宏实例 |
| 变量 | `VariableGetNodeHandler`、`VariableSetNodeHandler`、`SelfNodeHandler` | Get/Set 成员变量、Self 引用 |
| 字面量和运算 | `LiteralNodeHandler`、`PromotableOperatorNodeHandler`、`CommutativeAssociativeBinaryOperatorNodeHandler`、`EnumNameNodeHandler` | bool/int/float/string/text/name、算术/比较、枚举名 |
| 容器和结构体 | `GetArrayItemNodeHandler`、`MakeContainerNodeHandler`、`StructOperationNodeHandler` | Array Get、Make Array/Set/Map、Make/Break Struct |
| 文本和选择 | `FormatTextNodeHandler`、`SelectNodeHandler` | FormatText 参数、Select 输入类型 |
| 委托 | `AddDelegateNodeHandler`、`RemoveDelegateNodeHandler`、`AssignDelegateNodeHandler`、`CallDelegateNodeHandler`、`ClearDelegateNodeHandler`、`CreateDelegateNodeHandler` | 绑定、解绑、Assign、Call/Broadcast、Clear、Create Event |
| Timeline | `TimelineNodeHandler` | Timeline 创建、轨道输出、播放控制 pin |

## 验收标准

- 每个节点处理器至少有一个成功路径和一个失败/诊断路径。
- 导入后必须能通过 LogicJson 回读出 Agent 能理解的逻辑结构。
- 未支持节点必须失败得可诊断，不得静默丢节点或断链。

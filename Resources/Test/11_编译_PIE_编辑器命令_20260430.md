# 编译、PIE 与编辑器命令测试

## 通用测试前提

- 使用独立测试工程或 `/Game/BlueprintHelperTest/` 测试目录，不直接操作正式项目资产。
- 测试资产命名建议：
  - Blueprint：`/Game/BlueprintHelperTest/BP_BH_FunctionalActor.BP_BH_FunctionalActor`
  - WidgetBlueprint：`/Game/BlueprintHelperTest/WBP_BH_Test.WBP_BH_Test`
  - DataAsset：`/Game/BlueprintHelperTest/DA_BH_TestConfig.DA_BH_TestConfig`
  - DataTable：`/Game/BlueprintHelperTest/DT_BH_TestItems.DT_BH_TestItems`
- 除生命周期和构建测试外，默认 Unreal Editor 已启动，BlueprintHelper Bridge 可连接到 `BRIDGE_HOST:BRIDGE_PORT`。
- 所有破坏性测试必须在测试资产上执行；删除、导入、控制台命令、关闭编辑器、构建工程属于高风险或关键风险步骤。
- 写操作执行顺序默认是：读取当前状态 → 生成最小写入计划 → 执行写入 → 编译/校验 → 按需保存 → 读取回验。


## 覆盖对象

- `blueprint_compile_blueprint`
- `blueprint_undo`
- `blueprint_redo`
- `blueprint_play_in_editor`
- `blueprint_stop_pie`
- `blueprint_create_blueprint`
- `blueprint_exec_console_command`
- `blueprint_save_asset`
- `blueprint_close_editor`

## 测试用例

| ID | 功能 | 步骤 | 期望结果 | 优先级 |
|---|---|---|---|---|
| CMD-001 | 编译指定蓝图 | 调用 `blueprint_compile_blueprint`，传测试蓝图 | 返回 compiled true 或诊断；不依赖当前焦点 | P0 |
| CMD-002 | 编译当前蓝图 fallback | 打开测试蓝图后不传 target | 成功编译当前蓝图；无活动蓝图时明确错误 | P1 |
| CMD-003 | 编译失败诊断 | 构造编译错误蓝图后编译 | 返回错误列表、节点/图表上下文 | P0 |
| CMD-004 | Undo 添加变量 | 添加变量后调用 `blueprint_undo` | 变量消失；事务正确 | P0 |
| CMD-005 | Redo 添加变量 | 接 CMD-004 调用 `blueprint_redo` | 变量恢复 | P0 |
| CMD-006 | Undo 空栈 | 新会话未操作时调用 undo | 返回 NothingToUndo 或等价信息；不报崩溃 | P1 |
| CMD-007 | PIE 启动 | 调用 `blueprint_play_in_editor` | PIE session 启动；返回 success | P0 |
| CMD-008 | PIE 重复启动 | PIE 已运行时再次调用 | 返回 already running 或保持成功但状态明确 | P1 |
| CMD-009 | 停止 PIE | 调用 `blueprint_stop_pie` | PIE session 停止 | P0 |
| CMD-010 | 停止不存在 PIE | 无 PIE 时调用 stop | 返回 no PIE session 或成功 no-op，行为明确 | P1 |
| CMD-011 | 创建蓝图命令 | 调用 `blueprint_create_blueprint` 创建 Actor 子类 | 资产创建、可打开、可编译 | P0 |
| CMD-012 | 控制台命令安全白名单测试 | 调用低风险命令，如 `stat fps` 或查询命令 | 返回 output；无破坏性副作用 | P1 |
| CMD-013 | 控制台命令失败 | 调用不存在命令 | 返回命令失败/输出，不崩溃 | P1 |
| CMD-014 | 控制台高风险确认 | 尝试执行可能破坏状态的命令 | 测试流程要求人工确认，不允许 Agent 自动执行 | P0 |
| CMD-015 | 保存资产 | 修改测试资产后 `blueprint_save_asset` | 保存成功；dirty=false | P0 |
| CMD-016 | 关闭编辑器 | `blueprint_close_editor save_all=true` | dirty assets 保存；编辑器关闭 | P1 |
| CMD-017 | 命令组合流程 | create_blueprint → open_asset → add_variable → compile → save | 全流程成功；每步可回读验证 | P0 |

## 验收标准

- 编译和命令执行必须返回可读诊断。
- Undo/Redo 需要覆盖资产结构、Widget、DataTable、属性写入的事务一致性。
- PIE 与 close/editor/build 属于影响全局编辑器状态的操作，必须有明确状态返回。

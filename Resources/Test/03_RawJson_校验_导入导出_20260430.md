# RawJson 校验、导入导出与兼容性测试

## 通用测试前提

- 使用独立测试工程或 `/Game/BlueprintHelperTest/` 测试目录，不直接操作正式项目资产。
- 测试资产命名建议：
  - Blueprint：`/Game/BlueprintHelperTest/BP_BH_FunctionalActor.BP_BH_FunctionalActor`
  - WidgetBlueprint：`/Game/BlueprintHelperTest/WBP_BH_Test.WBP_BH_Test`
  - DataAsset：`/Game/BlueprintHelperTest/DA_BH_TestConfig.DA_BH_TestConfig`
  - DataTable：`/Game/BlueprintHelperTest/DT_BH_TestItems.DT_BH_TestItems`
- 除生命周期和构建测试外，默认 Unreal Editor 已启动，BlueprintHelper Bridge 可连接到 `BRIDGE_HOST:BRIDGE_PORT`。
- 所有破坏性测试必须在测试资产上执行；删除、导入、控制台命令、关闭编辑器、构建工程属于高风险或关键风险步骤。
- 写操作执行顺序默认是：读取当前状态 → 生成最小写入计划 → 执行写入 → 编译/校验 → 按需保存 → 读取回验。


## 覆盖对象

- `blueprint_validate_json`
- `blueprint_export_to_json`
- `blueprint_import_json_to_graph`
- `blueprint_compile_blueprint`
- `BlueprintHelperExportService`、`BlueprintHelperImportService`、`BlueprintHelperValidationService`
- RawJson 作为完整保真格式的导出、校验、导入和兼容性。

## RawJson 基础样例

```json
{
  "version": "BlueprintHelper.RawJson.v1",
  "graphs": [
    {
      "name": "EventGraph",
      "nodes": [
        { "id": "n_begin", "type": "Event", "event": "ReceiveBeginPlay" },
        { "id": "n_print", "type": "CallFunction", "function": "/Script/Engine.KismetSystemLibrary:PrintString" }
      ],
      "links": [
        { "from": "n_begin.Then", "to": "n_print.execute" }
      ]
    }
  ]
}
```

## 测试用例

| ID | 功能 | 步骤 | 期望结果 | 优先级 |
|---|---|---|---|---|
| RAW-001 | JSON 语法校验 | 调用 `blueprint_validate_json`，传入合法 JSON 字符串 | 返回 `valid:true` 或等价成功结果 | P0 |
| RAW-002 | JSON 语法错误 | 传入缺括号/非法逗号 JSON | 返回失败；错误定位包含 parse/line/column 或可诊断信息 | P0 |
| RAW-003 | 规则校验失败 | 传入缺 graph/nodes/link 必需字段的 JSON | 返回失败；不得进入导入执行阶段 | P0 |
| RAW-004 | 导出当前活动蓝图 | 打开测试蓝图，调用 `blueprint_export_to_json` 不传 target | 成功导出；结果包含蓝图结构；若无活动蓝图则返回明确错误 | P1 |
| RAW-005 | 显式蓝图导出 | 调用 `blueprint_export_to_json`，传 `target_blueprint` | 只导出目标蓝图，不依赖当前焦点 | P0 |
| RAW-006 | 显式图表导出 | 传 `target_blueprint` + `target_graph=EventGraph` | 只导出目标图表；节点与 links 数量正确 | P0 |
| RAW-007 | 无效蓝图路径导出 | target 指向不存在资产 | 返回 AssetNotFound 或等价错误；不崩溃 | P0 |
| RAW-008 | 无效图表导出 | target_graph 不存在 | 返回 GraphNotFound 或等价错误；不回退到当前图表 | P0 |
| RAW-009 | RawJson 严格导入成功 | 对测试蓝图 EventGraph 调用 `blueprint_import_json_to_graph`，`strict=true`、`compile_after_import=true` | 节点创建、链接连接、编译成功；返回 `nodes_created`、`links_connected` 或安全摘要 | P0 |
| RAW-010 | RawJson 非严格局部导入 | 提供一个可部分导入 JSON，`strict=false`、`allow_partial=true` | 可导入部分被创建；失败项进入 warnings/errors；不应全局崩溃 | P1 |
| RAW-011 | 严格导入链接失败回滚 | JSON 中包含不存在 pin 的 link，`strict=true` | 整次导入回滚；返回 `rolled_back:true` 或无新增节点；错误指向失败 link | P0 |
| RAW-012 | 重复导入幂等性 | 同一 RawJson 连续导入两次到测试图 | 第二次要么创建可区分节点，要么拒绝重复；不得生成损坏链接 | P1 |
| RAW-013 | 旧 Links 兼容 | 使用 `Resources/TestFixtures/LogicProcessor/compat_old_links.raw.json` 导入/校验 | 旧 link 结构可被兼容解析或返回明确迁移提示 | P1 |
| RAW-014 | Pin 类型字段验证 | 使用含 PinType 的 links/pins 结构导入 | 导入后 LogicJson/RawJson 中 pin 类型不丢失；Agent 可基于 pin 类型规划修改 | P0 |
| RAW-015 | LogicJson 误传 RawJson 导入 | 把 `*.logic.json` 传入 `blueprint_import_json_to_graph` | 返回失败，说明 LogicJson 不可导入；不得创建节点 | P0 |
| RAW-016 | 导入后编译失败诊断 | 导入一个语义不完整但结构合法的图 | 编译失败时返回 compile diagnostics；资产状态可回滚或可人工修复 | P1 |
| RAW-017 | 导入后保存策略 | 导入成功但 `compile_after_import=false` | 不自动保存，除非显式调用 `blueprint_save_asset` 或 profile 允许 | P1 |
| RAW-018 | 大蓝图导出稳定性 | 构造 10KB、50KB、100KB 蓝图图表导出 | 不超时；返回可解析 JSON；统计字段可用于性能对比 | P2 |

## 验收标准

- RawJson 保持完整保真，适合备份、精确重建和 link 调试。
- LogicJson/LogicMD 与 RawJson 职责不可混淆。
- 严格导入失败必须保护原资产，不能留下半导入节点或断链。

# 环境安装、MCP 连通性与生命周期测试

## 通用测试前提

- 使用独立测试工程或 `/Game/BlueprintHelperTest/` 测试目录，不直接操作正式项目资产。
- 测试资产命名建议：
  - Blueprint：`/Game/BlueprintHelperTest/BP_BH_FunctionalActor.BP_BH_FunctionalActor`
  - WidgetBlueprint：`/Game/BlueprintHelperTest/WBP_BH_Test.WBP_BH_Test`
  - DataAsset：`/Game/BlueprintHelperTest/DA_BH_TestConfig.DA_BH_TestConfig`
  - DataTable：`/Game/BlueprintHelperTest/DT_BH_TestItems.DT_BH_TestItems`
- 除生命周期和构建测试外，默认 Unreal Editor 已启动，BlueprintHelper Bridge 可连接到 `BRIDGE_HOST:BRIDGE_PORT`。
- 所有破坏性测试必须在测试资产上执行；删除、导入、控制台命令、关闭编辑器、构建工程属于高风险或关键风险步骤。
- 写操作执行顺序默认是：读取当前状态 → 生成最小写入计划 → 执行写入 → 编译/校验 → 按需保存 → 读取回验。


## 覆盖对象

- 本地生命周期工具：`blueprint_open_editor`、`blueprint_build_project`。
- Bridge 生命周期工具：`blueprint_get_editor_context`、`blueprint_close_editor`。
- 安装与运行前置：Node MCP Server、`UE_ENGINE_DIR`、`UE_PROJECT_FILE`、`BRIDGE_HOST`、`BRIDGE_PORT`、可选 `BLUEPRINTHELPER_BRIDGE_TOKEN`。

## 测试用例

| ID | 功能 | 前置条件 | 步骤 | 期望结果 | 优先级 |
|---|---|---|---|---|---|
| ENV-001 | MCP Server 启动 | `MCPServer/package.json` 存在 | 在插件根目录执行 `npm install`、`npm run build`；启动 MCP Server | TypeScript 编译通过；MCP Server 可被客户端发现 | P0 |
| ENV-002 | 工具注册数量 | MCP Server 可启动 | 读取 MCP 工具列表或运行现有 regression test | 工具数量为 44；无重复工具名；工具名与 API Reference 一致 | P0 |
| ENV-003 | Bridge 未启动错误 | UE 未启动 | 调用 `blueprint_get_editor_context` | 返回 `Bridge error` 或连接失败信息；MCP Server 不崩溃 | P0 |
| ENV-004 | Bridge 正常连通 | UE Editor 已启动且插件启用 | 调用 `blueprint_get_editor_context` | 返回 `success:true`；包含 active blueprint/graph 或明确说明无活动上下文 | P0 |
| ENV-005 | `blueprint_open_editor` 缺环境变量 | 不设置 `UE_ENGINE_DIR` 或 `UE_PROJECT_FILE` | 调用 `blueprint_open_editor` | 返回错误，明确要求设置 `UE_ENGINE_DIR` 与绝对 `.uproject` 文件路径 | P0 |
| ENV-006 | `blueprint_open_editor` 非 `.uproject` 路径 | `UE_PROJECT_FILE` 指向目录 | 调用 `blueprint_open_editor` | 返回错误，提示 `UE_PROJECT_FILE` 必须指向 `.uproject` 文件 | P0 |
| ENV-007 | `blueprint_open_editor` 成功启动 | UE 关闭，环境变量正确 | 调用 `blueprint_open_editor`，`wait_timeout_ms=120000` | UnrealEditor 进程启动；Bridge readiness ping 成功；返回 `EDITOR_BRIDGE_AVAILABLE` 或等价成功码 | P0 |
| ENV-008 | `blueprint_open_editor` 超时 | 设置很短 `wait_timeout_ms` | 调用 `blueprint_open_editor` | 返回 Bridge 超时；进程错误与 Bridge readiness 错误可区分 | P1 |
| ENV-009 | `blueprint_close_editor` 默认保存关闭 | 测试资产脏包存在 | 调用 `blueprint_close_editor`，不传 `save_all` | 默认保存所有 dirty package 并请求下一帧关闭；返回关闭中状态 | P0 |
| ENV-010 | `blueprint_close_editor` 不保存关闭 | 测试资产有可丢弃修改 | 调用 `blueprint_close_editor`，`save_all=false` | 不执行全局保存；编辑器退出；测试工程可重新打开 | P1 |
| ENV-011 | `blueprint_build_project` 缺环境变量 | UE 已关闭；缺 `UE_ENGINE_DIR` 或 `UE_PROJECT_FILE` | 调用 `blueprint_build_project` | 返回明确错误，不尝试构建 | P0 |
| ENV-012 | `blueprint_build_project` 默认参数 | UE 已关闭；环境变量正确 | 调用 `blueprint_build_project`，不传 target/config/platform | 默认 target 为 `<uproject>Editor`，configuration 为 `Development`，platform 为 `Win64`；构建输出可读 | P0 |
| ENV-013 | `blueprint_build_project` 指定配置 | UE 已关闭 | 调用 `blueprint_build_project`，`configuration=DebugGame` | 调用 UBT 成功或失败均返回完整 stdout/stderr；失败时包含 exit code | P1 |
| ENV-014 | 编辑器未关闭时构建保护 | UE 正在运行 | 调用 `blueprint_build_project` | 测试记录预期风险：可能因 LiveCoding/锁文件失败；文档要求先 close_editor | P1 |
| ENV-015 | Bridge Token 透传 | 设置 `BLUEPRINTHELPER_BRIDGE_TOKEN` | 调用任一 Bridge 工具 | Bridge 收到 token；未设置时不影响本地未加锁开发环境 | P2 |

## 失败诊断要求

- 连接失败应区分：MCP Server 启动失败、Bridge 端口不可达、Editor 未运行、token 不匹配、命令执行失败。
- 本地生命周期工具不得伪造 Bridge 成功：`blueprint_open_editor` 必须以 Bridge readiness 为最终可用标准。
- 构建工具失败时必须保留 stdout/stderr，便于定位 C++ 编译或 UBT 参数问题。

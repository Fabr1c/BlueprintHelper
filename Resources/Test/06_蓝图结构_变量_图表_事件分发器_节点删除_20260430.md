# 蓝图结构、变量、图表、事件分发器与节点删除测试

## 通用测试前提

- 使用独立测试工程或 `/Game/BlueprintHelperTest/` 测试目录，不直接操作正式项目资产。
- 测试资产命名建议：
  - Blueprint：`/Game/BlueprintHelperTest/BP_BH_FunctionalActor.BP_BH_FunctionalActor`
  - WidgetBlueprint：`/Game/BlueprintHelperTest/WBP_BH_Test.WBP_BH_Test`
  - DataAsset：`/Game/BlueprintHelperTest/DA_BH_TestConfig.DA_BH_TestConfig`
  - DataTable：`/Game/BlueprintHelperTest/DT_BH_TestItems.DT_BH_TestItems`
- 除生命周期和构建测试外，默认 Unreal Editor 已启动，BlueprintHelper Bridge 可连接到 `BRIDGE_HOST:BRIDGE_PORT`。
- 所有破坏性测试必须在测试资产上执行；删除、导入、控制台命令、关闭编辑器、构建工程属于高风险或关键风险步骤。
- 写操作执行顺序默认是：读取当前状态 → 生成最小写入计划 → 执行写入 → 编译/校验 → 按需保存 → 读取回验。


## 覆盖对象

- `blueprint_list_graphs`

- `blueprint_add_event_dispatcher`

|---|---|---|---|---|

| BPS-002 | 列出变量 | 调用 `blueprint_list_variables` | 返回变量名、类型、默认值、分类、flags | P0 |
| BPS-003 | 列出事件分发器 | 调用 `blueprint_list_event_dispatchers` | 返回 dispatcher 名称和参数 | P0 |
| BPS-004 | 添加 bool 变量 | `blueprint_add_variable`，`name=bIsActive`、`pin_type.category=bool`、`default_value=true` | 变量创建；回读存在；编译无错误 | P0 |
| BPS-005 | 添加 float 变量 | 添加 `Health` float，默认 `100.0`，category `Stats` | 类型、默认值、分类正确 | P0 |
| BPS-006 | 添加 object/class/struct 变量 | 分别使用 object/class/struct pin_type | 支持合法 object_path；非法路径返回错误 | P1 |
| BPS-007 | 添加容器变量 | 使用 Array/Set/Map 类 container_type | 容器类型回读正确；不支持类型返回明确错误 | P1 |
| BPS-008 | 重复变量名 | 再次添加 `Health` | 返回 DuplicateName；不得覆盖现有变量 | P0 |
| BPS-009 | 删除未引用变量 | 删除测试临时变量 | 成功删除；list_variables 回读不存在 | P0 |
| BPS-010 | 删除被引用变量 | 在图中创建 Get/Set 后删除变量 | 返回被引用/安全失败或要求确认；不得留下坏节点 | P0 |
| BPS-011 | 添加函数图 | `blueprint_add_graph`，`name=ComputeScore`、`graph_type=function`、设置 inputs/outputs | 函数图创建；签名正确；list_graphs 可见 | P0 |
| BPS-012 | 添加 pure 函数图 | `is_pure=true` | 函数纯度符合预期；输出 pin 合法 | P1 |
| BPS-013 | 添加宏图 | `graph_type=macro` | 宏图创建成功；list_graphs 分类正确 | P1 |
| BPS-014 | 重复图表名 | 再次添加 `ComputeScore` | 返回 duplicate graph | P0 |
| BPS-015 | 删除普通函数图 | 删除 `ComputeScore` | 删除成功；回读不存在 | P0 |
| BPS-016 | 删除 EventGraph 保护 | `blueprint_remove_graph`，`name=EventGraph` | 必须失败；不得删除核心图表 | P0 |
| BPS-017 | 添加无参事件分发器 | `blueprint_add_event_dispatcher`，`name=OnTestTriggered` | dispatcher 创建；list_event_dispatchers 可见 | P0 |
| BPS-018 | 添加带参事件分发器 | 添加 `OnHealthChanged(float NewHealth)` | 参数类型回读正确 | P0 |
| BPS-019 | 重复 dispatcher | 再次添加同名 dispatcher | 返回 duplicate name | P0 |
| BPS-020 | 删除节点 | 先用 AgentImport/RawJson 创建临时节点，记录 node_ids，再调用 `blueprint_delete_nodes` | 只删除指定节点；相关 links 被清理；编译无断链 | P0 |
| BPS-021 | 删除不存在节点 | `node_ids=["missing"]` | 失败或 warning；不得影响其他节点 | P0 |

| BPS-024 | 写操作显式目标 | 写工具传明确 `target_blueprint`/`target_graph` | 操作目标与当前编辑器焦点无关 | P0 |

## 验收标准

- 蓝图结构读写都能通过显式资产路径执行。
- 删除类操作具备保护和回滚策略。
- 添加变量、图表、dispatcher 后，LogicJson 和 RawJson 回读都能体现变化。

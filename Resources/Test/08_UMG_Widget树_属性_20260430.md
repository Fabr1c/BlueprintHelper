# UMG Widget 树与属性测试

## 通用测试前提

- 使用独立测试工程或 `/Game/BlueprintHelperTest/` 测试目录，不直接操作正式项目资产。
- 测试资产命名建议：
  - Blueprint：`/Game/BlueprintHelperTest/BP_BH_FunctionalActor.BP_BH_FunctionalActor`
  - WidgetBlueprint：`/Game/BlueprintHelperTest/WBP_BH_Test.WBP_BH_Test`
  - DataAsset：`/Game/BlueprintHelperTest/DA_BH_TestConfig.DA_BH_TestConfig`
  - DataTable：`/Game/BlueprintHelperTest/DT_BH_TestItems.DT_BH_TestItems`
- 除生命周期和构建测试外，默认 Unreal Editor 已启动，BlueprintHelper Bridge 可连接到 `BRIDGE_HOST:BRIDGE_PORT`。
- 所有破坏性测试必须在测试资产上执行；删除、导入、控制台命令、关闭编辑器、构建工程属于高风险或关键风险步骤。
- 写操作执行顺序默认是：读取当前状态 → 生成最小写入计划 → 执行写入 → 编译/校验 → 按需保存 → 读取回验。


## 覆盖对象

- `blueprint_get_widget_tree`
- `blueprint_add_widget`
- `blueprint_remove_widget`
- `blueprint_move_widget`
- `blueprint_get_widget_properties`
- `blueprint_set_widget_property`
- `BlueprintHelperWidgetService`

## 测试用例

| ID | 功能 | 步骤 | 期望结果 | 优先级 |
|---|---|---|---|---|
| UMG-001 | 读取 Widget 树 | 对测试 WBP 调用 `blueprint_get_widget_tree` | 返回 RootWidget、子节点层级、Widget 类型、名称 | P0 |
| UMG-002 | 空/简单 Widget 树 | 对只有 CanvasPanel root 的 WBP 读取 | 返回合法空树，不报错 | P0 |
| UMG-003 | 添加 TextBlock 到 root | `blueprint_add_widget`，`widget_class=TextBlock`、`widget_name=TitleText` | 节点创建；回读树中存在 `TitleText` | P0 |
| UMG-004 | 添加 Button 到 Panel | `widget_class=Button`、`parent_name=RootCanvas`、`widget_name=StartButton` | Button 在指定父节点下 | P0 |
| UMG-005 | 添加到不存在 parent | parent_name 不存在 | 返回 ParentNotFound；不创建孤立 Widget | P0 |
| UMG-006 | 无效 widget_class | widget_class=NoSuchWidget | 返回 InvalidClass；树不变 | P0 |
| UMG-007 | 重复 widget_name | 再次添加 `TitleText` | 返回 DuplicateName 或自动唯一化；行为需稳定记录 | P1 |
| UMG-008 | 读取 Widget 属性 | `blueprint_get_widget_properties`，`widget_name=TitleText` | 返回 Text、Visibility、RenderTransform、Slot 等可编辑属性 | P0 |
| UMG-009 | 设置 Text 属性 | `blueprint_set_widget_property`，`property_name=Text`、`value="Hello"` 或 UE text import | 回读 Text 值一致 | P0 |
| UMG-010 | 设置 Visibility | value=Visible/Collapsed | 回读枚举值正确；非法枚举失败 | P1 |
| UMG-011 | 设置 Slot 属性 | 设置 CanvasPanelSlot Anchors/Offsets/Alignment | 布局属性回读一致 | P1 |
| UMG-012 | 设置不存在属性 | property_name=MissingProperty | 返回 PropertyNotFound；Widget 不变 | P0 |
| UMG-013 | 移动 Widget | `blueprint_move_widget`，将 `TitleText` 移到 `StartButton` 或另一 Panel | 层级改变；原父节点移除；新父节点插入 | P0 |
| UMG-014 | insert_index | 添加多个子节点后指定 index 移动 | 顺序符合 index；越界返回错误或 append 行为明确 | P1 |
| UMG-015 | 移动到非法父节点 | new_parent 是不支持 children 的 Widget | 返回 InvalidSlot/InvalidParent；树不变 | P0 |
| UMG-016 | 删除普通 Widget | `blueprint_remove_widget`，删除 `TitleText` | 树中不存在；相关引用清理 | P0 |
| UMG-017 | 删除不存在 Widget | 删除 MissingWidget | 返回 WidgetNotFound；树不变 | P0 |
| UMG-018 | 删除 root 保护 | 删除 RootWidget | 必须失败；root 不变 | P0 |
| UMG-019 | 编译与保存 | UMG 修改后编译/保存 | WidgetBlueprint 可编译；保存后重开树一致 | P1 |
| UMG-020 | Undo/Redo 兼容 | 添加 Widget 后 undo/redo | Widget 添加/撤销/恢复状态正确 | P1 |

## 验收标准

- Widget 树操作必须能处理 parent、slot、index 与 root 保护。
- 属性写入必须依赖 UE 属性反射/文本导入格式，非法值不得破坏 WidgetBlueprint。
- 删除与移动后需要回读树验证结构一致。

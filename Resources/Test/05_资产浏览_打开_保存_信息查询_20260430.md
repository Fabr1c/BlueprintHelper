# 资产浏览、打开、保存与信息查询测试

## 通用测试前提

- 使用独立测试工程或 `/Game/BlueprintHelperTest/` 测试目录，不直接操作正式项目资产。
- 测试资产命名建议：
  - Blueprint：`/Game/BlueprintHelperTest/BP_BH_FunctionalActor.BP_BH_FunctionalActor`
  - WidgetBlueprint：`/Game/BlueprintHelperTest/WBP_BH_Test.WBP_BH_Test`
  - DataAsset：`/Game/BlueprintHelperTest/DA_BH_TestConfig.DA_BH_TestConfig`
  - DataTable：`/Game/BlueprintHelperTest/DT_BH_TestItems.DT_BH_TestItems`
- 除生命周期和构建测试外，默认 Unreal Editor 已启动，BlueprintHelper Bridge 可连接到 `BRIDGE_HOST:BRIDGE_PORT`。
- 所有破坏性测试必须在测试资产上执行；删除、导入、控制台命令、关闭编辑器、构建工程属于高风险或关键风险步骤。
- 写操作执行顺序默认是：读取当前状态 → 生成最小写入计划 → 执行写入 → 编译/校验 → 按需保存 → 读取回验。


## 覆盖对象

- `blueprint_list_assets`
- `blueprint_search_assets`
- `blueprint_open_asset`
- `blueprint_save_asset`
- `blueprint_get_asset_info`
- `blueprint_create_blueprint`
- `BlueprintHelperAssetBrowseService`

|---|---|---|---|---|
| AST-001 | 列出根目录资产 | 调用 `blueprint_list_assets`，`path=/Game`、`recursive=false` | 返回 `/Game` 下一层资产/目录；结果数量受 `max_results` 控制 | P0 |
| AST-002 | 递归列出测试目录 | 调用 `blueprint_list_assets`，`path=/Game/BlueprintHelperTest`、`recursive=true` | 返回测试目录内全部资产 | P0 |
| AST-003 | class_filter Blueprint | `class_filter=Blueprint` | 只返回 Blueprint 或 BlueprintGeneratedClass 相关资产 | P1 |
| AST-004 | name_filter | `name_filter=BH` | 只返回名称包含 BH 的资产 | P1 |
| AST-005 | max_results | 设置 `max_results=1` | 返回最多 1 条；有截断/总数信息更佳 | P1 |
| AST-006 | 无效路径 | `path=/NotGame` | 返回 InvalidContentPath 或等价错误；不崩溃 | P0 |
| AST-007 | 搜索资产 | 调用 `blueprint_search_assets`，`query=BP_BH` | 返回匹配蓝图资产；路径可直接用于后续工具 | P0 |
| AST-008 | 搜索空结果 | `query=DefinitelyMissingAssetName` | 返回空数组而非错误，除非路径无效 | P1 |
| AST-009 | 打开 Blueprint 资产 | 调用 `blueprint_open_asset`，传测试蓝图路径 | 编辑器打开资产；返回 success | P0 |
| AST-010 | 打开 WidgetBlueprint | 调用 `blueprint_open_asset`，传 WBP 路径 | 编辑器打开 WidgetBlueprint | P1 |
| AST-011 | 打开不存在资产 | 传不存在路径 | 返回 AssetNotFound；不回退到当前资产 | P0 |
| AST-012 | 获取资产信息：Blueprint | 调用 `blueprint_get_asset_info` | 返回 class、package、dirty、path 等资产信息 | P0 |
| AST-013 | 获取资产信息：DataTable/DataAsset | 分别传 DataTable 和 DataAsset | 返回对应类型、行结构或类信息；无编辑器焦点依赖 | P1 |
| AST-014 | 创建 Blueprint | 调用 `blueprint_create_blueprint`，`asset_path=/Game/BlueprintHelperTest/BP_BH_Created`、`parent_class=Actor` | 创建资产成功；可被 list/search/get_asset_info 找到 | P0 |
| AST-015 | 创建重复 Blueprint | 再次使用同一路径创建 | 返回 duplicate asset 错误；不得覆盖已有资产 | P0 |
| AST-016 | 创建无效 parent_class | `parent_class=NoSuchClass` | 返回 invalid parent class；不得创建半成品资产 | P0 |
| AST-017 | 保存资产 | 修改测试蓝图变量后调用 `blueprint_save_asset` | dirty 状态清除；磁盘资产更新 | P0 |
| AST-018 | 保存不存在资产 | 传不存在路径 | 返回 AssetNotFound/SaveFailed；不保存其他资产 | P0 |

## 验收标准

- 所有资产工具必须支持显式路径，不应依赖当前焦点。
- 查询工具返回的路径必须能作为后续 open/save/info 的输入。
- 创建和保存操作必须限定测试目录，避免污染正式内容目录。

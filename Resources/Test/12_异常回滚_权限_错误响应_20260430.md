# 异常、回滚、权限与错误响应测试

## 通用测试前提

- 使用独立测试工程或 `/Game/BlueprintHelperTest/` 测试目录，不直接操作正式项目资产。
- 测试资产命名建议：
  - Blueprint：`/Game/BlueprintHelperTest/BP_BH_FunctionalActor.BP_BH_FunctionalActor`
  - WidgetBlueprint：`/Game/BlueprintHelperTest/WBP_BH_Test.WBP_BH_Test`
  - DataAsset：`/Game/BlueprintHelperTest/DA_BH_TestConfig.DA_BH_TestConfig`
  - DataTable：`/Game/BlueprintHelperTest/DT_BH_TestItems.DT_BH_TestItems`
- 除生命周期和构建测试外，默认 Unreal Editor 已启动，BlueprintHelper Bridge 可连接到 `BRIDGE_HOST:BRIDGE_PORT`。
- 所有破坏性测试必须在测试资产上执行；删除、导入、控制台命令、关闭编辑器、构建工程属于高风险或关键风险步骤。
- 写操作执行顺序默认是：读取当前状态 → 生成最小写入计划 → 执行写入 → 编译/校验 → 按需保存 → 读取回验。


## 覆盖对象

- 全部高风险写工具的错误路径。
- `BlueprintHelperScopedAssetMutation`、Bridge Guard、Strict Import Diagnostics、Mutation Transaction、Verification Gate。
- MCP 错误响应、safety result fields：`effective_scope`、`status`、`operations_applied`、`nodes_created`、`links_connected`、`warnings`、`errors`、`rolled_back`。

## 测试用例

| ID | 风险点 | 步骤 | 期望结果 | 优先级 |
|---|---|---|---|---|
| SAF-001 | Bridge 不可达 | 关闭 UE 后调用任意 Bridge 工具 | MCP 返回连接错误；进程不崩溃 | P0 |
| SAF-002 | 缺 target_blueprint | 对高风险写工具不传目标 | 应拒绝或只允许明确 active-context；错误提示要求显式目标 | P0 |
| SAF-003 | 缺 target_graph | 对节点导入/删除不传 graph | 应拒绝或提示需要 graph；不得误操作当前图 | P0 |
| SAF-004 | AssetNotFound | 所有 asset_path 工具传不存在路径 | 返回 AssetNotFound；不改其他资产 | P0 |
| SAF-005 | GraphNotFound | 所有 target_graph 工具传不存在图 | 返回 GraphNotFound；不回退 | P0 |
| SAF-006 | JsonParseFailed | validate/import 传非法 JSON | 返回 parse error；无写入 | P0 |
| SAF-007 | ContractValidationFailed | AgentImport 传缺 schema/version | 返回合约错误；无写入 | P0 |
| SAF-008 | UnsupportedNodeKind | AgentImport 传未知 `kind` | 返回 unsupported kind；严格模式回滚 | P0 |
| SAF-009 | InvalidPin | 导入无效 pin link | 返回 pin 诊断；`rolled_back=true`；节点数不变 | P0 |
| SAF-010 | Import partial rollback | 导入中途失败 | 原图快照恢复；无孤立新增节点 | P0 |
| SAF-011 | Delete protected graph | 删除 EventGraph | 必须失败；图仍存在 | P0 |
| SAF-012 | Delete protected root widget | 删除 root widget | 必须失败；Widget 树不变 | P0 |
| SAF-013 | Delete used variable | 删除仍被节点引用的变量 | 必须失败或要求确认；不得留下坏引用 | P0 |
| SAF-014 | DataTable duplicate row | 添加重复 row | 返回 duplicate；旧 row 不变 | P0 |
| SAF-015 | Property unsafe flag | 写只读/非 Edit 属性 | 返回 unsafe/not editable；值不变 | P0 |
| SAF-016 | Console critical command | Agent 请求自动执行高风险控制台命令 | 测试期望：需要人工批准；无批准不得执行 | P0 |
| SAF-017 | Close editor confirmation | Agent 自动关闭编辑器 | 测试期望：需要人工批准或明确用户请求 | P0 |
| SAF-018 | Build while editor open | 未 close editor 调 build | 返回可诊断失败或文档提示风险；不得误报成功 | P1 |
| SAF-019 | Response safety summary | 任意写入成功/失败 | MCP 结果附带 safety fields 或可替代摘要 | P0 |
| SAF-020 | 幂等 retry | 网络中断后 Agent 尝试重试导入 | 不允许盲目重试；必须先 read state 判断是否已部分应用 | P0 |
| SAF-021 | Undo recovery | 写入成功但验证失败后 undo | 资产恢复；再次读取确认 | P1 |
| SAF-022 | Save 失败处理 | 模拟只读磁盘/锁文件保存失败 | 返回 SaveFailed；内存状态与磁盘状态区别明确 | P2 |
| SAF-023 | 错误码稳定性 | 对常见错误运行快照测试 | `error_code`/message 不发生无意义变更 | P2 |
| SAF-024 | 当前焦点误操作防护 | 打开 A 蓝图，命令目标为 B 蓝图 | 操作只影响 B；A 不变 | P0 |

## 验收标准

- P0 错误必须可被 Agent 自动分类：目标不存在、图不存在、JSON 解析、合约失败、pin 失败、编译失败、权限/确认不足、Bridge 不可达。
- 高风险写入失败必须无副作用或可通过事务撤回。
- 错误响应必须足够短，但保留定位信息。

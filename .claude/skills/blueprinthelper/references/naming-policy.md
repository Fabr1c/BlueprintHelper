# Naming Policy

Generated Blueprint names should be searchable and business-specific.

Prefer function names with a verb and object, such as `ApplyDamage`, `RefreshInventoryList`, or `ValidateInteractionTarget`.

Avoid low-semantic names such as `DoIt`, `Handle`, `Update`, `Process`, `Logic`, `Temp`, and `NewFunction`.

Event Dispatchers should describe the event, commonly `OnEventName` or the project convention.

New public variables and functions should include useful category, tooltip, or comments when supported.

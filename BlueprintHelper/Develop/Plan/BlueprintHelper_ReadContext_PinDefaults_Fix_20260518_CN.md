# BlueprintHelper ReadContext Pin 默认值通用修复记录

日期：2026-05-18

## 问题

读取蓝图逻辑时，未连接输入 Pin 的默认值可能没有完整暴露。典型表现包括：

1. `SetActorTickEnabled` 等函数节点的布尔默认值可能不出现在 LogicJson。
2. 浮点、文本、Object/Class 默认值在 raw graph 中存在，但 LogicJson 不稳定暴露。
3. LogicJson 的归一化节点只保留节点和连线语义，未透传 raw graph 已导出的 `inputs`。

## 原因

原始图表导出只读取 `UEdGraphPin::DefaultValue`，没有覆盖以下 UE Pin 默认值来源：

1. `AutogeneratedDefaultValue`
2. `DefaultObject`
3. `DefaultTextValue`

同时，LogicJson group builder 没有把 raw node 的 `inputs`、`input_defaults`、`outputs` 复制到逻辑节点输出中。

## 修复内容

1. 在图表导出层新增通用未连接数据输入 Pin 默认值提取逻辑。
2. 默认值读取顺序为 `DefaultValue`、`AutogeneratedDefaultValue`、`DefaultObject`、`DefaultTextValue`。
3. 保留向后兼容的 `inputs` 简单键值输出。
4. 新增 `input_defaults` 结构化输出，包含 `value`、`source`、`connected`、`pin_type`。
5. LogicJson 节点透传 `inputs`、`input_defaults`、`outputs`。

## 期望结果

1. Agent 读取 LogicJson 时能看到未连接数据输入 Pin 的有效默认值。
2. Agent 可以根据 `input_defaults.*.source` 判断默认值来自 UE 的哪类 Pin 字段。
3. 该能力不绑定具体节点，适用于函数调用、变量节点、结构节点及后续新增 K2 节点。

## 距离期望的差距

1. 当前修复覆盖导出和 LogicJson 透传链路。
2. 尚未添加自动化用例覆盖 `bool false`、`float 0.0`、`Text`、`Object/Class` 默认值。
3. 尚未执行编辑器端 read_context 覆盖测试。
